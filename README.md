# Yogo Voyage

A modern, responsive Tour & Travel website for **Yogo Voyage**, built with Next.js, TypeScript and Tailwind CSS.

## Getting Started

```bash
cd wanderindia-travels
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Brand

- Logo: `public/logo.jpg`
- Navy: `#1A4789`
- Gold: `#EBB531`

Update company details in `src/data/company.ts`.
